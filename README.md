# TCL Home Comfort Market Research

A visual version of my starting market research on TCL North America's Home Comfort line: products, closest competitors, customer themes and growth ideas.

Independent research from public sources. Not affiliated with or endorsed by TCL. Prices and specs change, so every item links to its source.

## Run it
Open `index.html` in a browser. No build step.

## Edit the facts
All content lives in `data/data.js`. Each product points to source ids listed at the bottom of that file.

## What is and is not confirmed
The site lists unconfirmed items openly (see "Not yet confirmed"). Built with AI assistance.

Live site: https://victordelgadopm.github.io/tcl-home-comfort-market-research/
